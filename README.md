# 0x03. Shell, Variables, Expansions

## 📖 Description

This project covers the basics of the Shell, focusing on aliases, environment variables, local variables, shell expansions, and basic arithmetic.

---

## 🚀 File Descriptions (Tasks)

Each file is a script that performs a specific task:

- **`0-alias`**: A script that creates an alias named `ls` with the value `rm *`.
- **`1-hello_you`**: A script that prints "hello " followed by the current Linux username.
- **`2-path`**: A script that adds the `/action` directory to the end of the `PATH` environment variable.
- **`3-paths`**: A script that counts the number of directories listed in the `PATH` variable.
- **`4-global_variables`**: A script that lists all environment variables.
- **`5-local_variables`**: A script that lists all local variables, environment variables, and functions.
- **`6-create_local_variable`**: A script that creates a new local variable named `BEST` with the value `School`.
- **`7G-create_global_variable`**: A script that creates a new global (environment) variable named `BEST` with the value `School`.
- **`8-true_knowledge`**: A script that prints the result of adding 128 to the value stored in the `TRUEKNOWLEDGE` variable.
- **`9-divide_and_rule`**: A script that prints the result of `POWER` divided by `DIVIDE` (both are environment variables).
- **`10-love_exponent_breath`**: A script that displays the result of `BREATH` to the power of `LOVE` (both are environment variables).
- **`11-binary_to_decimal`**: A script that converts a binary number (stored in the `BINARY` variable) to its decimal (base 10) equivalent.
- **`12-combinations`**: A script that prints all possible two-letter combinations (a-z), except for `oo`.
- **`13-print_float`**: A script that prints the number stored in the `NUM` variable with two decimal places.
